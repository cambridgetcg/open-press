open-press

The lens reads a sentence; the press reads the world.

A framework for evidence-tiered, signed newspapers that anyone can run. The sibling of captioneer / open-lens — the same truth-work, at the scale of a day's news. Every number wears a tier; refuted claims are executed in public; every edition ships hashed and signed; combatant quotes hand off to the lens automatically.

Your own paper in three lines

node press.mjs new "The Morning Ledger"   # scaffold press.config.json
#   ... write an edition.json (copy examples/) ...
node press.mjs build my-edition.json       # render · hash · sign · archive

The four tiers — the fixed spine

✓ verifiedsurvived adversarial verification ◑ reportedanonymous-official journalism — repeated ≠ confirmed ○ claimeda combatant's own statement — auto-links to the lens ✗ refutedkilled in verification — struck through, never deleted
